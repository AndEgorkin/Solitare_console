SOLITAIRE

Console Edition

By Andrei Egorkin (AKA Kuprisel)

Recommended Python version: 3.14.10
Run solitare.py to start playing

The game follows the standard rules of Solitaire Klondike

T is 10
XX is a closed card
-- is an empty space

Controls:
General rule: row 0 is the top row, row 1 is the main field. You should enter coordinates of where do you want to take card(s) from and put card(s) to

Enter: 1 0
to flip a card from the deck

Enter: 2 0
to take card from deck on top left and put it in main field by: 'column' 1
or put it to the top spaces by: 'column' 0

Enter: 'column' 1
to take card(s) from the main field and enter: 'column' 1 to put it into another column of the main field after it enter the amount of cards from bottom of the column you want to move
or enter: 'column' 0 to move a card on the top spaces

Enter 'column' 0
to take a card from the top row and 'column' 1 to put it on main field

Enter 0 0
to end game



No AI used
